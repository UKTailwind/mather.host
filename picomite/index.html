PicoMite

MMBasic for the Raspberry Pi RP2040 and RP2350. Flash one file onto a Pico and it becomes a self-contained computer with a full-screen editor, graphics, sound, a file system and hundreds of built-in commands for driving hardware.

VT2350 terminal

A VT100-and-beyond terminal for a Pico 2: 640×480 HDMI, USB keyboard and mouse, and two UARTs or up to four USB serial devices. It's designed to sit in front of a PicoMite, and it answers the PicoMite's screen-size query by choosing a font to fit.

  • xterm 256 colours, UTF-8 and VT52 (via libvterm)
  • Up to 128×59 characters, with scrollback
  • No data loss at 460,800 baud in testing

Games in BASIC

The Bas folder holds full games written in MMBasic. They show how far the language and the graphics engine can be pushed. They include versions of Elite, Thrust, Exile and Chuckie Egg, plus Picanoid and "Prince of Pico".

Planning documents for several of these ports are on the AI page.
