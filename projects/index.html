tiny386

Accuracy fixes for this small 386 PC emulator, which runs Windows 9x on an ESP32: IRETD in real mode, the single-step trap, triple-fault reset, the PS/2 mouse sample rate, the 8250 serial port's interrupts, and the memory size that Windows 95 Setup reads from CMOS.

μSQLite

Hardening for the SQLite module for MicroPython: a separate SQLite heap, garbage-collector-safe memory, 64-bit integers, recovery from power failure, and large sorts that spill to SD or flash. It's used by the Pico Computer 3 MicroPython port.

Double-precision floating-point instructions for the assembler, and Cortex-M7 cache cleaning after compiling. Both were merged into upstream development branches.

MMB4W: MMBasic for Windows

MMBasic as a Windows program, built on the olcPixelGameEngine. It has graphics, sprites, turtle graphics and GUI controls, plus JPEG/PNG decoding and WAV, MP3, FLAC and MOD playback.

MMX: Micromite eXtreme

MMBasic for Microchip's PIC32MZ2048EF in 64-, 100- and 144-pin packages, running at 200 or 252 MHz. The repository is a placeholder for the source.

gcode-to-bambu-preset

Reads the print settings from G-code or 3MF files made by Simplify3D, Cura or PrusaSlicer/SuperSlicer/OrcaSlicer, and writes Bambu Studio process and filament presets. It's a single Python script with no dependencies.
