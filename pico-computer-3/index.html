Pico Computer 3

A complete home computer on one board, built around the Raspberry Pi RP2350B. Plug in an HDMI screen and a USB keyboard, then choose an operating system: MMBasic, MicroPython or the FUZIX Unix-like OS.

Hardware

CPU
RP2350B, the 80-pin RP2350 with 48 GPIO
Memory
8 MB PSRAM plus on-board flash
Video
HDMI/DVI from the RP2350's HSTX
Audio
PCM5102 stereo DAC
USB
On-board hub for keyboard, mouse, gamepads and flash drives
Storage
SD card
Clock
DS3231 real-time clock
Console
USB-C serial

PicoMite PC3 build

A dedicated PicoMite firmware build for the board. It gives MMBasic HDMI graphics, USB devices, sound and the SD card out of the box. The same build also runs on the Pico Computer 2 and the Olimex RP2350pc.

MicroPython for the PC3

A MicroPython board port that turns the PC3 into a self-contained Python computer. Much of its hardware support is carried over from the PicoMite.

  • HDMI graphics with sprites, blitting, layers and 3D
  • USB keyboard, mouse, gamepad and drives
  • MOD player, synth, Wi-Fi, file manager and GUI library
  • A desktop emulator, and a beginner's book: Programming the Pico Computer 3

Based on MicroPython.

FUZIX for the PC3

A port of the FuzixOS small Unix-like operating system to the board, with an on-board C toolchain and an MMBasic-to-C translator.

  • HDMI console, PSRAM, USB keyboard, sound, SD card and RTC
  • Wi-Fi networking with a TFTP server
  • New bytecode and ARM Thumb compiler back ends, so C compiles on the board
  • mmb2c: translates MMBasic programs to C
  • BBC BASIC, awk and man pages

Based on FuzixOS.

VT2350

The VT100-compatible terminal firmware has a PC3 board option. With it, the PC3 becomes an HDMI serial terminal for another computer, such as a PicoMite.

pc3host

The FUZIX-side MMBasic toolchain running natively on a PC. You can translate, compile and run PC3 programs in a desktop window. A device server stands in for the board's kernel.

  • Graphics, keyboard, sound, and MP3/FLAC/MOD playback
  • Networking with TLS
  • .deb package and a self-contained Windows zip
