The first beta, 8.00.00b1, was posted on 16 November 2026. The same firmware file runs on all three generations of the board.

Release notes →

WiFi and the Internet

With the WiFi module on the rear I/O connector, the CMM2 runs the WebMite's networking unchanged: a web server, HTTP and HTTPS clients, UDP, MQTT, network time, a Telnet console and TFTP file transfer.

HDMI on the Generation 3

A Generation 2 whose picture goes out through HDMI, with the sound on the monitor's speakers and the audio socket at once. Every video mode shows, from power up, and OPTION DVI suits monitors that want DVI.

Programs run from RAM

The BASIC program lives in 512 KB of SDRAM and is never written to the flash, so loading is quicker and editing never wears it. With OPTION AUTORUN ON, AUTORUN.BAS on the card starts at power up.

USER modules

Commands and functions of your own, written in C, that a BASIC program calls like the built-in ones. The SQL command works the same way, with SQLite as its module.

Coming from V7? Save your program and your options to the SD card before you update, because V8 uses the part of the flash where V7 kept the program. Afterwards, load the options again and reload your library from its source files. The release notes' "Before you update" section has every step. 7.00.00RC6 is the last V7 release and stays available.

Web pages from BASIC

Type OPTION WIFI "MyNetwork", "secret" and OPTION TCP SERVER PORT 80 once at the prompt, and a BASIC program can serve web pages to any browser on your network. This is a whole server:

WEB TRANSMIT PAGE sends an HTML file from the SD card and fills in anything between curly brackets with its value, so a page shows live readings with no extra code:

Buttons and fields in a form come back to the program as requests it can act on. A graph drawn with the CMM2's graphics commands can be saved as a PNG and sent as an image. Several browsers can connect at once.

Also on the network

  • HTTPS and TCP clients to fetch data from web services, with the server's certificate checked if you want (WEB TLS CA)
  • MQTT: publish and subscribe through a broker
  • UDP messages to and from other devices
  • WEB NTP sets the clock from a time server
  • A Telnet console: the prompt and the editor from a PC, with nothing plugged into the serial port
  • TFTP copies files to and from a PC

The network code is the WebMite's, unchanged, so a WebMite program runs as it is apart from the I/O pins it uses. Geoff Graham's Garden Watering Controller runs with only its pins changed.

PicoMite programs, unaltered

The CMM2 and the PicoMite now run the same MMBasic, so a PicoMite program's BASIC is already right. What differs is the hardware, and OPTION PICOMITE covers that. Set it at the prompt, or put OPTION PICOMITE HDMI at the top of the program so that it applies to that program alone, and the program sees the PicoMite it was written for.

It gets far more room: about 4 MB for variables on a Generation 1, and 15 MB on a Generation 2 or 3. The PicoMite's own test programs run on every release as part of the CMM2's regression tests.

Programs that use hardware the CMM2 doesn't have, such as the PIO, LCD panels or cameras, still need changes. The User Manual's Porting Programs chapter lists them.

Display
MODE is the PicoMite's: 1 to 3 on VGA, 1 to 5 on HDMI, with its framebuffers, layers and screen memory for PEEK and POKE.
Resolutions
640x480 at 60 or 75 Hz, 720x400, 800x600 and 848x480, and with HDMI also 800x480, 1024x600, 1280x720 and 1024x768.
Pins
GP0, GP1 and the rest name the rear connector's pins with the same functions. The PicoMite's SETPIN for COM ports, I2C, SPI, PWM and IR is accepted.
Drives
B: is the SD card, as on the PicoMite, and so is A:. C: is a USB drive on both.
CSUBs
A PicoMite CSUB that uses only MMBasic's call table runs as it is.
Name
MM.DEVICE$ returns the PicoMite's name, so a program that sets itself up by it does so as on that PicoMite.

  • ScummVM for LucasArts and Sierra adventures, with three free games. Add Monkey Island, Day of the Tentacle and others from your own copies.

Classic computers

  • ZX Spectrum 48K and 128K, Amstrad CPC 464, 664 and 6128, Commodore 64 with its 1541 drive
  • Atari 400/800, XL/XE and 5200, Apple //e, BBC Micro and Master 128, TRS-80 Model I, III, 4 and 4P
  • Amiga 500 at its own 50 frames a second, with your own Kickstart (G2 or G3)

Languages

  • MMBasic V8, built in, with a full-screen editor and a file manager
  • MicroPython, the Pico Computer 3's, with modules for the screen, sound, keyboard, mouse, SQLite, ulab and the I/O pins
  • A C compiler that runs on the machine, with no PC. It compiles MMBasic programs too, so one that spends its time calculating runs much faster.
  • zeptoforth, a Forth with preemptive tasks, double-precision arithmetic and a screen editor

Write your own

  • Loadable programs in C or C++, built on a PC with the SDK
  • USER modules that add commands to BASIC

Utilities

  • WordGrinder, a word processor that exports ODT for Word and LibreOffice, HTML and Markdown, and checks spelling on a G2 or G3
  • sc-im, a spreadsheet worked from the keyboard like vi, that reads and writes CSV
  • SQLite databases from BASIC with the SQL command, with a sample database to try
  • A VT100 terminal that makes the CMM2 the screen and keyboard of a PicoMite or another computer, in colour, with the mouse, scrollback and XMODEM

Built into MMBasic

Before any app is loaded, the firmware itself has plenty for games, graphics and control:

  • 19 video modes up to 1920 x 1080, with pages, sprites, tile maps, a 3D engine, turtle graphics and the PicoMite's raycaster for first-person views
  • Sound: WAV, FLAC, MP3 and MOD files, the BBC Micro's sound, and an FM synthesiser that plays MIDI
  • SQL databases (SQLite), long strings and regular expressions
  • USB keyboards, mice, gamepads and touch screens, with an on-screen keyboard
  • Control: stepper motors, CAN bus, WS2812 LEDs, infrared remotes and the PicoMite's astronomy commands, which can point a telescope

The source is in the CMM2V1.5 repository. Version 8 is on its v8-dev branch, and main stays at version 7.

Installing 8.00.00b1

  1. Download CMM2_MMBasic_8.00.00b1.bin, and the programs zip if you want the apps, from the release.
  2. If you're coming from V7, save your program to the SD card and your options with OPTION DISK SAVE "A:/myoptions".
  3. Type UPDATE FIRMWARE, or set the PGM jumper (the BOOT CONFIG switch on a Waveshare board) for a first install. Connect the CMM2's keyboard USB port to a PC with an A-to-A cable, and write the .bin with ST's free STM32CubeProgrammer over USB.
  4. Put the jumper or switch back if you moved it, press reset, then OPTION DISK LOAD "A:/myoptions", and LIBRARY LOAD your library's files again if you use one.
  5. Unzip the programs on a PC and copy the folders you want to the root of the SD card.

Appendix K of the User Manual walks through STM32CubeProgrammer with screenshots. This is a beta, so please report problems on The Back Shed forum.
