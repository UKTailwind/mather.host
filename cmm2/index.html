Colour Maximite 2

A 480 MHz STM32H743 computer that boots straight into BASIC, with VGA graphics, sound and an SD card. The firmware is being brought up to the same V7 MMBasic interpreter as the PicoMite, and one firmware file runs on both the G1 and G2 boards.

MMBasic V7 for the CMM2

The CMM2V1.5 tree ports the PicoMite's V7 interpreter back to the Colour Maximite 2, and adds features that make use of the STM32H7's speed and memory:

  • Loadable C/C++ programs: MicroPython, Doom, Heretic, ScummVM, a NES emulator and a 386 PC emulator that runs DOS and Windows 3.1
  • A C compiler that runs on the machine
  • SQL databases (SQLite) from BASIC
  • OPTION PICOMITE runs PicoMite VGA and HDMI programs unchanged
  • USB touch screens with an on-screen keyboard, stepper-motor control, and an FM synth that plays MIDI
  • The CMM2's 18 video modes, 3D engine, sprites and CAN bus, all kept

It builds with CMake, Ninja and the GCC from STM32CubeIDE, and is flashed with an ST-Link.

CMM2 WiFi module

A board that plugs onto the rear I/O header, passes it through, and adds WiFi with the same radio as the Pico W. MMBasic V8 gives it the PicoMite's networking: a web server, HTTPS client, UDP, MQTT, network time, telnet and TFTP.

zeptoforth on the M7

Contributions to zeptoforth, a Forth for Cortex-M chips: double-precision floating-point instructions for its assembler, and cache cleaning after compiling on the Cortex-M7. Both changes were merged upstream.
