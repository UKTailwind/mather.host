Pico Computer 3 or Colour Maximite 2 G3?

Both switch on into BASIC, plug into an HDMI screen and run the same MMBasic, the same MicroPython and the same book. One is built around the low-cost RP2350B, the other around a 480 MHz STM32H743 with 32 MB of SDRAM. Which is better for playing, for learning and for making new things? The answer is different for each.

18 November 2026PicoMite V7.00.00CMM2 MMBasic 8.00.00b2

In short

  • For playing: the G3. Doom, Quake, ScummVM and a shelf of classic-computer emulators load from its SD card, and on the G3 they play on a 1080p TV with the sound coming out of it.
  • For making things: the PC3. WiFi, Bluetooth, the RP2350's programmable I/O and a Qwiic socket come on a small, low-cost board, and a program finished on it runs on a Pico 2 W.
  • For learning: either. The same MicroPython and the same book run on both. The PC3 adds a Unix-like operating system and the CMM2 adds a Forth.
  • For speed: the CMM2. Its 480 MHz Cortex-M7 and SDRAM run Python about twice as fast as the PC3, and big BASIC programs have far more room.

The two machines

The Pico Computer 3 is an RP2350B home computer that runs MMBasic, MicroPython or FUZIX. The G3 is the newest Colour Maximite 2: a Generation 2 board whose picture and sound go out through HDMI instead of VGA. Since MMBasic V7 the two run the same interpreter, so most of what follows is about the hardware around it.

For playing

The G3 is the games machine

The CMM2's programs zip holds 21 loadable programs, and most of them are for fun:

  • Games: Doom with the free Freedoom data and its music on the FM synthesiser, Heretic, Quake, ScummVM for LucasArts and Sierra adventures, and a NES emulator.
  • Classic computers: the ZX Spectrum, Amstrad CPC, Commodore 64 with its 1541, Atari 8-bit machines, Apple //e, BBC Micro and Master, TRS-80, an Amiga 500 at its own 50 frames a second, and a 386 PC that runs DOS, Windows 3.1 and Windows 95.

The G3 adds the part that was missing. A G1 or G2 needs a VGA monitor and speakers; a G3 takes one HDMI cable to a TV, shows every video mode from the moment it's switched on, and plays the sound through the TV's speakers and the audio socket at once. MMBasic itself has sprites, tile maps, a 3D engine, the PicoMite's raycaster and an FM synthesiser that plays MIDI, with 32 MB of SDRAM behind them.

The PC3's fun is the kind you make

The PC3 has no shelf of ported games, but MMBasic games written for it run well. With the compiler on at 378 MHz, an Elite game draws a frame in 11.0 ms and a Prince of Persia port in 6.7 ms (the V7 timings). It has four USB ports for a keyboard, mouse, gamepad and flash drive, Bluetooth keyboards and mice, MOD, MP3 and FLAC playback and the BBC Micro's sound. Its headphone socket is driven by a 32-bit DAC, cleaner than the CMM2's 12-bit one.

The book Programming the Pico Computer 3 builds Breakout, Asteroids and a tile-map adventure in Python, and those run on either machine.

For learning

Both machines start in MMBasic with a full-screen editor and a file manager, so a beginner types a line and sees it run. Both run the PC3's MicroPython, and the CMM2's MicroPython app runs every example in the book. After that they part ways:

  • The PC3 can become a small Unix machine. FUZIX gives it a shell, a C compiler that runs on the board, mmb2c to turn MMBasic programs into C, BBC BASIC, awk and man pages. pc3host runs the same toolchain on a Windows or Linux PC.
  • The CMM2 keeps everything on one SD card, with no reflashing to change language. It has a C compiler that runs on the machine and also compiles MMBasic programs, zeptoforth, and an SDK for writing loadable programs and new BASIC commands in C or C++.

For making things

The PC3

  • Wireless as standard. Every PC3 can serve web pages, talk MQTT, set its clock by NTP, fetch from HTTPS services and be edited over Telnet, with nothing added.
  • Programmable I/O. The RP2350's PIO state machines run your own serial protocols and timing at full speed. Nothing on the STM32 does that.
  • Plug-in sensors. The Qwiic/STEMMA QT socket takes hundreds of sensor and display boards from SparkFun, Adafruit, Pimoroni and others with no soldering. The PicoMite's camera support works too.
  • A way to finish. Try an idea on the PC3 with a screen and keyboard, then run the same program on a Pico 2 W in the finished gadget. The PicoMite's builds share one MMBasic.
  • Cheap to dedicate. A board this small and inexpensive can be given to a single project and left there.

The CMM2

  • Room and precision. About 15 MB for variables and double-precision maths in hardware suit big arrays, data logging, image work and calculation.
  • Control. CAN bus, stepper motors, a DAC, the Wii controllers, infrared remotes, WS2812 LEDs, and with the WiFi module the PicoMite's networking unchanged.
  • Data. SQLite databases from BASIC with the SQL command.
  • Extending the language. USER modules add your own commands and functions, written in C, that BASIC calls like built-in ones.
  • A workstation for PicoMite code. With OPTION PICOMITE it runs PicoMite programs unaltered, so it's a comfortable place to write code that ends up on a Pico.

Before you choose

The G3

  • Its firmware is a beta. G3 support began with MMBasic V8, which is at 8.00.00b2, so there's no full release to fall back on yet.
  • It's a new design, so you have it made from the published files. The STM32H743 costs several times what the RP2350B does.
  • It can't reach a low-speed keyboard, mouse or gamepad through a hub. How to choose full-speed devices.

The PC3

  • Its 8 MB of PSRAM is on a serial bus, so a program working through large arrays runs slower than it would in the CMM2's SDRAM.
  • Its picture tops out at 1280 × 720, and the many-colour modes are at lower resolutions.
  • It runs one system at a time: changing between MMBasic, MicroPython and FUZIX means loading different firmware.

Which one?

  • A games and retro-computing machine for the TV, or the most room for a big BASIC program: the G3.
  • Gadgets, sensors and connected devices, a low-cost machine for a class, or a project that will end up on a Pico: the PC3.

Or both. They share MMBasic, MicroPython and the book, so programs move between them: a PicoMite program runs on the CMM2 with OPTION PICOMITE, and Python written from the book runs on either.
